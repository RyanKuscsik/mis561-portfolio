One thing Power BI does automatically is allow me to transform the data and create new columns directly within Power BI. In Flex 3 or Flex 4, I had to make these changes manually in Excel before uploading the data into Tableau. Next time, I would choose Power BI because it makes the data preparation process more efficient by allowing me to edit and create columns without needing to switch between different programs.
