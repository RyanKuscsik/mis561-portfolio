One thing Power BI does automatically is allow me to transform the data and create new columns directly within Power BI. In Flex 3 or Flex 4, I had to make these changes manually in Excel before uploading the data into Tableau. Next time, I would choose Power BI because it makes the data preparation process more efficient by allowing me to edit and create columns without needing to switch between different programs.

Introduction to DAX in Power BI, 9/30/2026, https://public.tableau.com/views/PowerBITrainingCertifications_17906185940810/PowerBIStory?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link
In Flex 4 I calculated the discount in dollars in Excel by taking list price minus revenue for each order ID, then used that in Tableau. In Power BI I'd make it a calculated column, because it's just a fixed number tied to one order that doesn't change no matter what anyone filters, so it only needs to be figured out once when the data refreshes. Having it as a column also means people can filter or group by it, like pulling up every order discounted more than $500, which you can't do with a measure. If that number lives in the model, Anita and Marcus don't have to ask me to go back into the Excel every time new orders come in. They can filter to the heavily discounted orders themselves, and it stays up to date when the data changes.
